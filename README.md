# GH-100 — Course Learning Space

Welcome! This repository is my personal learning space for the **GH-100** course. It's a sandbox for working through lessons, trying out concepts hands-on, and keeping notes, exercises, and experiments all in one place.

> **Note:** This is a learning repo. Expect work-in-progress code, rough notes, and experiments. Nothing here is intended for production use.

## Purpose

- Practice the concepts covered in each module of the course
- Keep a running log of notes, takeaways, and questions
- Experiment with Git and GitHub workflows (branches, pull requests, issues, Actions, etc.)
- Build a reference I can come back to after the course ends

## Repository Structure

The layout will grow as the course progresses, but the general plan is:

```
GH-100/
├── README.md          # You are here
├── notes/             # Module-by-module notes and summaries
├── exercises/         # Hands-on labs and practice work
├── experiments/       # Scratch space for trying things out
└── resources/         # Links, cheat sheets, and reference material
```

Each module gets its own folder (e.g. `notes/module-01/`, `exercises/module-01/`) so progress is easy to follow.

## How I Use This Repo

1. **One branch per module or exercise** — keeps work isolated and makes it easy to practice pull requests.
2. **Issues as a to-do list** — open an issue for each lab or question, close it when done.
3. **Commit often** — small, descriptive commits that explain _why_, not just _what_.
4. **Notes alongside code** — every exercise folder includes a short `NOTES.md` with what I learned.

## Getting Started

Clone the repo:

```bash
git clone git@github.com:ejohnguia/GH-100.git
cd GH-100
```

Create a branch for a new module or exercise:

```bash
git checkout -b module-01/intro
```

When finished, push the branch and open a pull request to `main` to review the work.
